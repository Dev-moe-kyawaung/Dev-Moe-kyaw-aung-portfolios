## 🚀 Quick Start

### Prerequisites
- Node.js >= 18.0.0
- npm >= 9.0.0
- Git

### Installation

```bash
# Clone the repository
git clone https://github.com/Dev-moe-kyawaung/moekyawaung-portfolio.git
cd moekyawaung-portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```
# Development Command
```
# Development
npm run dev              # Start all dev servers
npm run dev:html         # Vanilla HTML/CSS/JS
npm run dev:vue          # Vue 3 version
npm run dev:react        # React 18 version
npm run dev:next         # Next.js 14 version

# Build
npm run build            # Build all versions
npm run build:html       # Build vanilla version
npm run build:analyze    # Bundle analysis

# Deploy
npm run deploy:github    # GitHub Pages
npm run deploy:netlify   # Netlify
npm run deploy:vercel    # Vercel

# Quality
npm run lint             # ESLint
npm run format           # Prettier
npm run test             # Vitest
npm run test:e2e         # Playwright
npm run lighthouse       # Lighthouse CI
npm run a11y             # Accessibility audit
```
